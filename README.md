# Our Little Question Jar

Romantic, responsive two player question game built with React, Vite and Supabase. Player credentials are random 256-bit bearer tokens stored per room in local storage; the database stores only SHA-256 token hashes. All answer reads and writes go through token-checking database functions. A separate Realtime mirror publishes room state without answer text or credentials.

## Run locally

1. Install Node.js 20+ and run `npm install`.
2. Copy `.env.example` to `.env`, then set the Supabase project URL and anon key.
3. Apply the migrations in `supabase/migrations/` with the Supabase CLI (`supabase db push`) or SQL Editor. Existing projects must apply the new `202610310002_validate_analysis.sql` migration.
4. Redeploy the semantic scoring function: `supabase functions deploy analyze-answers`.
5. Set `OPENAI_API_KEY` as an Edge Function secret (`supabase secrets set OPENAI_API_KEY=...`). Optionally set `OPENAI_MODEL`.
6. Run `npm run dev`.

Enable Realtime for `room_events` (the migration adds it to `supabase_realtime`). Configure HTTPS and a static-site rewrite so `/room/<code>` falls back to `index.html`.

## Notes

- The server deadline is authoritative for the shared countdown. The browser timer only displays it.
- Refresh recovery is supported on the same browser/device through the saved room token. A joined player should keep their invite tab/device to reconnect.
- Analysis is generated by the deployed Edge Function, with the OpenAI secret kept server side. The frontend invokes it with the room code and player token after the room reaches `revealed`; the validated JSON result is stored on the room.
- The scoring function validates the score and every required comparison field before storage; the database has a matching shape/range constraint. If the AI returns malformed or incomplete content, the UI shows a retry state instead of a fake score or generic comparison.
- This project is delivered without Supabase project credentials, so live two-session deployment requires the configuration above.
